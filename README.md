# Blurt

**基于火山引擎豆包 API 的 Windows 极速语音输入工具，为 Vibe Coding 与高效生产力而生。**

按下快捷键，说出想法，中英混合文本即刻精准落入 Claude Code、Cursor、VS Code、浏览器或任何终端光标处。

![Blurt 设置界面](public/settings.png)

---

## 核心特性

- **极速云端流式识别**：基于豆包流式语音大模型 1.0，录音与识别端到端毫秒级并行。
- **纯神经静音端点检测**：内置轻量 [Silero-VAD](https://github.com/snakers4/silero-vad) ONNX 深度学习模型，智能判断语音起止，告别传统音量门限误判。
- **流体动画 HUD**：无边框彩色光球动效，清晰提示录音、识别与完成状态。
- **多模式文本输入**：支持智能判断、模拟键盘键入与剪贴板快速粘贴（自动恢复原剪贴板）。
- **安全存储**：API Key 保存于 Windows 凭据管理器，配置文件不记录明文密钥。
- **使用统计**：内置字数统计、时长记录、30 天趋势图与活跃热力图。

## 交互方式

| 阶段 | 动画效果 | 说明 |
|------|----------|------|
| 按下快捷键 | 彩色光球随声音跳动 | 正在录音 |
| 停止说话 | 光球聚拢旋转 | 正在识别 |
| 识别完成 | 光球淡出消失 | 文字输入完成 |
| 取消或出错 | 红色抖动或快速消失 | 录音取消或识别失败 |

- **按住说话**（长按 >= 350ms）：按住快捷键说话，松开立即识别并输入。
- **点击切换**（单击 < 350ms）：按一下开始录音，再按一下或停顿后自动结束，适合长句输入。
- **取消录音**：按 `Esc` 随时取消。
- **打开设置**：双击托盘图标或再次打开软件即可进入设置。

## 快速上手

1. 下载并运行 `Blurt.exe`。
2. 打开设置，填入火山引擎豆包语音服务的 API Key。
3. 状态显示“已就绪”后，按下快捷键（默认 `Ctrl + Alt`，可自定义）即可开始说话。

---

## 技术架构

- **底层框架**：Tauri 2 + Rust（原生轻量，内存占用约 30MB）。
- **静音检测**：Silero-VAD（ONNX 本地轻量端点检测模型）。
- **音频采集**：CPAL 原生流式采集。
- **前端实现**：原生 HTML5 Canvas + CSS。

## 从源码构建

环境要求：Rust (MSVC 工具链)、Visual Studio C++ Build Tools、WebView2。

```powershell
# 1. 生成图标与资源
pwsh -File scripts/make-icons.ps1

# 2. 编译与运行
cd src-tauri
cargo test
cargo build --profile release-fast
```

构建产物位于 `src-tauri\target\release-fast\blurt.exe`。
