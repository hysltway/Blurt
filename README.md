# Blurt

**基于火山引擎豆包 API 的 Windows 极速语音输入工具，为 Vibe Coding 与高效生产力而生。**

按下快捷键，说出想法，中英混合文本即刻精准落入 Claude Code、Cursor、VS Code、Windows Terminal、微信或任何应用的光标处。

![Blurt 设置界面](public/settings.png)


## 为什么做 Blurt？

在日常开发与电脑办公中，语音输入能极大地释放双手与思维，但现有方案总有遗憾：
1. 市面上的商业语音输入软件（如 Typeless）价格昂贵，不愿为单纯的输入工具持续按月付费。
2. 现存的免费/离线方案或配置繁琐，或识别准确率与响应速度达不到日常主力标准。
3. 虽然 Codex、Claude 等各家 AI 工具常内置语音功能，但体验割裂、识别质量参差不齐；特别是对于 **CLI / 终端重度用户**，命令行环境下一直缺乏好用的全局语音输入。
4. 不仅是写代码，在电脑微信聊天、文档撰写、网页搜索等各种桌面场景下，同样需要随时随地即说即输入的流畅体验。

**基于此，Blurt 诞生了。**


## 为什么选择 Blurt？

- 完全开源免费，零订阅套路，代码透明且易于按需定制。
- 基于 Rust + Tauri 2 构建，极速响应，后台常驻内存仅约 30MB，极低系统资源占用。
- 搭载火山引擎豆包流式语音大模型，毫秒级响应，中英混合识别极高精度，输入体验直接拉满。
- 支持智能光标检测、模拟按键与剪贴板输入，随处可用。
- 内置轻量 [Silero-VAD](https://github.com/snakers4/silero-vad) ONNX 深度学习模型，智能判断语音起止，告别传统音量门限误判。
- API Key 保存于 Windows 凭据管理器，配置文件不记录明文密钥。



## 交互方式

| 阶段 | 动画效果 | 说明 |
|------|----------|------|
| 按下快捷键 | 彩色光球随声音跳动 | 正在录音 |
| 停止说话 | 光球聚拢旋转 | 正在识别 |
| 识别完成 | 光球淡出消失 | 文字输入完成 |
| 取消或出错 | 红色抖动或快速消失 | 录音取消或识别失败 |

- **按住说话**（长按 >= 350ms）：按住快捷键说话，松开立即识别并输入。
- **点击切换**（单击 < 350ms）：按一下开始录音，再按一下或停顿后自动结束，适合长句输入。
- **取消录音**：按 `Esc` 随时取消。
- **打开设置**：双击托盘图标或再次打开软件即可进入设置。



## 快速上手

1. 下载并运行 `Blurt.exe`。
2. 打开设置，填入火山引擎豆包语音服务的 API Key。
3. 状态显示“已就绪”后，按下快捷键（默认 `Ctrl + Alt`，可自定义）即可开始说话。



## 技术架构

- **底层框架**：Tauri 2 + Rust（原生轻量，内存占用约 30MB）。
- **静音检测**：Silero-VAD（ONNX 本地轻量端点检测模型）。
- **音频采集**：CPAL 原生流式采集。
- **前端实现**：原生 HTML5 Canvas + CSS。



## 📌 当前局限与展望

- **深层语义重构与智能润色**：已支持服务端基础语义顺滑（自动剔除“呃”、“啊”等口头停顿词），对于长难句倒装、复杂口语转专业书面语的端侧 LLM 极速语义精修仍在持续探索中。
- **跨平台与多端拓展**：目前专注于 Windows 原生体验的极致打磨，未来可考虑探索 macOS 等多平台生态。
- **自定义语音指令与工作流**：探索语音宏与上下文感知的快捷操作联动，进一步拓宽生产力边界。



## 从源码构建

环境要求：Rust (MSVC 工具链)、Visual Studio C++ Build Tools、WebView2。

```powershell
# 1. 生成图标与资源
pwsh -File scripts/make-icons.ps1

# 2. 编译与运行
cd src-tauri
cargo test
cargo build --profile release-fast
```

构建产物位于 `src-tauri\target\release-fast\blurt.exe`。
